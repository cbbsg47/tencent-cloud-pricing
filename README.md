## 标价之外，还有三件事影响你每月实际掏多少钱

**第一，付款周期比配置更能左右单价。** 轻量 2核2G4M 一年 99 元、三年 368 元，后者月均 10.2 元，比年付还低一点。CVM 更明显：SA2 2核4G 三年 1915.2 元，摊到每月 53.2 元；如果按年买同样配置，单价通常高出一截。代价是钱要先付出去，中途改主意不好退。

**第二，流量包和「不限流量」是两种完全不同的计费方式。** 轻量应用服务器标的是峰值带宽，同时给一个月流量包，2核2G3M 给 200GB、4核8G12M 给 2000GB。CVM 标的是固定带宽，不限流量。同样写着 3M，如果你的站真能把带宽跑满，轻量的流量包会先见底；所以轻量适合流量可预期的站点，CVM 适合流量大但不想盯着流量表看的业务。

**第三，续费价才是第二年的真实成本。** 页面上明确标注「同价续费、新老用户同享」的机型只有两款：2核2G4M（99 元/年）和 2核4G6M（企业 199 元/年）。秒杀价和首购特价通常只作用于第一个周期，其余机型续费前建议先在控制台查一遍续费价，别只看首年数字。

## 先买小配置再升配，会不会更亏

不会亏太多，腾讯云官方文档写得很清楚：包月实例升配按天补差价，公式是「升配费用 = 按月升配差价 × 升配月数 × 适用折扣」，升配月数等于剩余天数除以 (365/12)，而且升配不影响原来的到期时间。

官方文档里有个示例：1核1G（65 元/月）买了 1 年，用了 4 个月后升到 2核4G（218 元/月），剩余 244 天，按月升配差价 153 元，适用 88 折，最后补 1080.07 元。也就是说你只为「升级后的这段时间」补钱，不是重新买一遍。

反过来，降配要走退款流程：退款金额等于原实例退费减去新规格新购费用，算下来小于等于 0 就不退钱。买大了再往回缩，可能一分钱拿不回来。

所以拿不准配置时，先买小一号、后面升配，比一步到位买大、发现用不上再降配要稳妥。

## 什么情况下轻量应用服务器不适合你

轻量便宜，但它把网络和存储都打包好了，能改的地方少。以下情况直接看 CVM：

- 业务流量波动大，需要按量计费、随时开关机
- 要挂载多块云硬盘，或者跟同账号下的数据库、对象存储走内网
- 需要自定义安全组、私有网络、负载均衡
- 要跑深度学习、视频转码，得用 GPU 机型

轻量应用服务器的定位是「一台机器搞定一个项目」，超出这个范围，省下来的钱会以折腾的形式还回去。
